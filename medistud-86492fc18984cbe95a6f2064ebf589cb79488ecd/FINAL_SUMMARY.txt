🚀 QUICK START

1. START SERVER
   $ cd /vercel/share/v0-project
   $ pnpm dev
   → Server runs on http://localhost:3000

2. OPEN MEDICAL RECORDS
   → http://localhost:3000/medical-records
   → Login: admin@pticlinic.com / password

3. SEARCH STUDENT MEDICAL FILE
   → Enter matric number (e.g., MTH/21/001)
   → Click Search
   → View complete medical profile

4. GENERATE REPORTS
   → http://localhost:3000/reports
   → Select report type
   → Set date range
   → Click Generate
   → View report with analytics
