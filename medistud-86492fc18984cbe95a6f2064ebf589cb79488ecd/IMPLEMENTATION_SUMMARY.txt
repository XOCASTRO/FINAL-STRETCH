================================================================================
API ENDPOINTS
================================================================================

AUTHENTICATION
POST /api/auth/login
├─ Input: { email, password }
└─ Output: { token, user details, permissions }

MEDICAL RECORDS
POST /api/medical-records/create
├─ Input: { matric_number, student_name, date_of_birth, level, ... }
├─ Validation: Format + Uniqueness
└─ Output: 201 Created or error

GET /api/medical-records/{matric_number}
├─ Input: Matric number
├─ Authorization: Bearer token
└─ Output: Complete medical file with all records

GET /api/medical-records/{matric_number}/allergies
GET /api/medical-records/{matric_number}/prescriptions
GET /api/medical-records/{matric_number}/treatments
└─ All with full CRUD operations

STAFF MANAGEMENT
POST /api/staff/create
├─ Input: { email, full_name, password, role, permissions }
├─ Validation: Email uniqueness, password hash
└─ Output: 201 Created or error

GET /api/staff
├─ Authorization: Must have can_create_staff permission
└─ Output: List of all staff users

DATABASE SCHEMA
================================================================================

staff_users TABLE
├─ staff_id (INT, PRIMARY KEY)
├─ email (VARCHAR, UNIQUE)
├─ password_hash (VARCHAR, bcrypt)
├─ full_name (VARCHAR)
├─ role (VARCHAR: ADMIN, DOCTOR, NURSE, STAFF, VIEWER)
├─ can_create_records (BOOLEAN)
├─ can_create_staff (BOOLEAN)
├─ can_edit_records (BOOLEAN)
├─ can_delete_records (BOOLEAN)
├─ department (VARCHAR)
├─ is_active (BOOLEAN)
└─ created_at, updated_at (TIMESTAMP)

student_files TABLE
├─ matric_number (VARCHAR, PRIMARY KEY: m.YY/CODE/XXXXXX)
├─ student_name (VARCHAR)
├─ level (VARCHAR: 100-500)
├─ date_of_birth (DATE)
├─ phone, email, address (VARCHAR/TEXT)
├─ parent_contact, emergency_contact (VARCHAR)
├─ created_by_staff_id (INT, FOREIGN KEY)
└─ date_created, date_updated (TIMESTAMP)

Related Tables (linked via matric_number):
├─ allergies
├─ treatment_history
├─ prescription_history
├─ doctor_notes
├─ clinic_visits
├─ financial_transactions
└─ clinic_activities

HOW TO USE
================================================================================

STEP 1: SETUP DATABASE
$ mysql -u root -p < mysql-schema.sql
$ node scripts/init-db.js

STEP 2: CONFIGURE ENVIRONMENT
Create .env.local:
MYSQL_HOST=localhost
MYSQL_USER=root
MYSQL_PASSWORD=your_password
MYSQL_DATABASE=clinic_db

STEP 3: START SERVER
$ pnpm dev

STEP 4: LOGIN
URL: http://localhost:3000/login
Email: admin@pticlinic.com
Password: admin123

STEP 5: CREATE MEDICAL RECORD
1. Navigate to Medical Records
2. Click "Create Record"
3. Enter matric number (e.g., m.24/nd/001234)
4. Fill student information
5. Submit form

STEP 6: SEARCH MEDICAL RECORD
1. Go to Medical Records page
2. Enter matric number in search
3. Click Search
4. View complete medical profile
